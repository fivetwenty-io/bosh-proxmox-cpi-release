# BOSH Director Upgrade Test

The [BOSH CPI certification](https://github.com/cloudfoundry/bosh-cpi-certification) suite's Director Upgrade Test stands a Director up on one CPI release, deploys the upstream certification release under it, upgrades the Director in place onto a newer CPI release, and recreates the deployment through it. We run it against a Proxmox VE lab with `./scripts/certify`; [BOSH Director Upgrade Test](../upgrade.md) documents the setup and invocation.
